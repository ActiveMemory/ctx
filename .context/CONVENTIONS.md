## Themes

- code style — code shape: naming, casing, predicate form, line width, dedup, error wrapping → [code style](conventions/code-style.md)
- layout — on-disk layout: file/dir organization, maintainer-only binary placement → [layout](conventions/layout.md)
- workflow — working discipline: when to change code, how to decide, refactoring, test shape → [workflow](conventions/workflow.md)
- docs — docs: typography and document shape, doc conventions, blog publishing → [docs](conventions/docs.md)
- cli — cli: command structure, keeping the user-facing surface complete → [cli](conventions/cli.md)
